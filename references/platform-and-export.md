# 平台核验与交付

## 规则来源

Ozon 规则可能随类目、图片位置和后台更新而变化。优先核对当前卖家后台对应位置的提示和官方文档；运营文章、搜索摘要和竞品图片只能作参考。

官方入口：<https://docs.ozon.ru/global/>。查找 `Требования к изображениям`、`Фото товара` 或“商品图片要求”，不要编造细则页面或来源。

创建本技能时（2026-09-13），官方入口返回连接错误，未成功核实当日图片细则。因此本文件不记录已确认的官方像素、文件大小或张数上限。以后核验成功时，在当前任务中记录页面标题、URL、日期、适用类目/位置和关键限制，不把单类目规则扩散成全站规则。

| 核验项 | 影响的决定 |
| --- | --- |
| 主图、补充图或其他内容位置 | 是否允许文字、拼图、场景等信息 |
| 宽高比、最小/最大像素 | 工作画布与导出尺寸 |
| 格式、色彩模式、文件大小 | 编码、色彩转换与压缩 |
| 张数、顺序与类目专属限制 | 套图分工和上传排列 |
| 背景、商品展示与内容限制 | 摄影风格和营销元素 |

来源冲突时比较日期与适用范围，以能确认适用于当前 SKU 和上传位置的要求为依据。不确定时明确保留该限制，不能用“别人这么做”证明允许。

暂时无法核验时仍可设计，采用下方内部预设，注明“平台要求待核验”。可以交付设计成图，但不能称其已通过 Ozon 合规检查或保证可上传。用户已提供当前后台要求时直接应用，不重复索取。

## 内部预设：设计建议，不是平台标准

- 未指定尺寸时，可从 **1200 × 1600 px、3:4 竖版**开始制作商品卡片图。优先服从已核实的类目要求和用户尺寸；正方形、横版另设画布，不能直接拉伸。
- 同一序列使用一致画布。重要文字距边缘约短边的 5%–7%，并检查实际预览裁切；此比例是留白起点，不是平台安全区。
- 摄影成图可优先高质量 JPEG；需要无损细节且该位置支持时用 PNG。交付使用 sRGB；其他 ICC 配置的素材需要实际转换，不能仅删除标签。
- 保留较高分辨率的素材和底图，最后统一排版导出。不默认放大低清素材，不把普通放大宣传为真实细节增强。
- 默认省略短期价格、折扣、倒计时、配送时效及无依据的销量/评价。需要促销图时，按真实活动数据与当前位置规则判断。

## 导出检查

检查实际文件是否可解码、像素和宽高比、格式、字节数、颜色与透明通道、EXIF 旋转方向和异常压缩痕迹，不只检查生成参数。透明素材合成 JPEG 前明确底色，避免变黑。内容正确性仍需对照事实和视觉查看。

按已确认的限制控制体积；未核验时不要随意设定“官方最大 MB”。为使用方便压缩时，保留清楚的文字、轮廓与细小结构。

遵循用户指定目录与当前工作区规则。未指定时，交付图片放工作区输出目录，中间底图和草稿放工作目录；保留原始素材，修改后另存版本。

示例命名：`SKU123_01_main_ru_v1.jpg`、`SKU123_02_feature_ru_v1.jpg`。使用真实 SKU；未知时用中性商品简称，不捏造货号。预览图可以标明图序，但不把预览编号装饰写入上传成图。

交付说明区分实际状态：设计成图已生成/保存/查看；平台规则已核对哪些部分；是否实际上传及看到了什么结果。做图请求本身不包含上架发布操作。无需输出未涉及的状态清单；未能生成或查看文件时，明确交付是方案、提示词或尚未完成视觉检查的文件。
