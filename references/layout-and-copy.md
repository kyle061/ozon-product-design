# 版式与俄语文案

## 按购买问题安排图片

从下表选择合适图片，不机械凑数量。主图先让买家知道卖的是什么；能否加文字及可用内容，以当前类目和位置要求为准。

| 图片任务 | 买家要知道什么 | 画面重点 | 需要的依据 |
| --- | --- | --- | --- |
| 主图 | 是什么，是否是所需款式 | 清楚实物、简洁背景、必要时一个核心信息 | 当前 SKU 实拍、主图规则 |
| 核心卖点 | 哪项特征解决问题 | 一个特征的近景或使用示意 | 参数或真实结构 |
| 材质/工艺 | 细节和质感 | 真实细节放大、克制标注 | 高清实拍、材质资料 |
| 尺寸/规格 | 是否放得下或适配 | 轮廓、正确尺寸线、单位 | 实测/规格表、长宽高顺序 |
| 使用场景 | 怎样使用 | 可信环境、真实尺度 | 使用条件和实际支持的用法 |
| 包装清单 | 到手有哪些东西 | 实物与配件逐项排列 | 当前 SKU 的数量和清单 |
| 使用/安装 | 如何开始使用 | 少量连续步骤 | 说明书或真实流程 |
| 款式比较 | 该选哪个版本 | 真实差异、突出当前 SKU | 各版本明确参数 |

信息不足时缩减页面，不把“材质高级”“品质更好”等抽象重复句拆成多张图。

## 视觉系统

- 根据实物与品牌确定一个方向。家居可用柔和生活感；3C 可突出结构和参数；服饰强调真实颜色、版型与面料。它们是可选方向，不是固定类目模板。
- 通常采用一个主色、一个强调色与中性色。包装复杂时，用背景帮助分离轮廓。
- 主体大小以完整展示和识别速度决定；细长、成套或带线缆的商品不硬套固定占比。
- 以 1200 px 宽画布为例，可从主标题 72–100 px、支持信息 40–56 px 试排，最终由 300 px 宽预览可读性决定。文字过多时先精简，不一味缩小。
- 每图一个主信息，支持信息通常两三条以内，不用徽章、箭头和色块填满空白。
- 保持统一字体、标题对齐、圆角与标注线。比较设计方向时，优先只改变一个主要变量，方便判断。

## 中文转自然俄语

先确认通用商品名称，再表达真实特征与价值。中文营销话术需要改写，不逐字硬译，不强行塞入搜索关键词。

主标题通常从 2–5 个俄语词起写，每图一个含义；完整性优先于字数，名称较长时合理换行。校验名词性/数/格、形容词配合、介词搭配和专业术语。

选用覆盖西里尔字母且有使用权限的字体，如环境中可用的 Noto Sans 或其他已验证字体。检查 `Й`、`Ё`、`Ы`、`Ж` 等字符、粗体和数字，避免缺字替换。买家文案用俄语，真实品牌、型号和必要标准代号保留原文。

单位常用写法：`500 мл`、`1,5 л`、`25 × 15 × 8 см`、`2 шт.`、`220 В`、`65 Вт`。实际数字必须来自资料；尺寸图明确长宽高方向。可控排版时，数字与单位之间使用不换行空格。

以下只是语言示例，不能作为任意商品的事实：

| 中文意图 | 有依据时可用的俄语 | 使用条件 |
| --- | --- | --- |
| 桌面收纳盒 | `Настольный органайзер` | 商品类型与用途吻合 |
| 节省空间 | `Экономит место` | 结构、尺寸或场景支持 |
| 可拆卸结构 | `Разборная конструкция` | 确实可拆装 |
| 两件套 | `В комплекте 2 шт.` | 此 SKU 确实包含两件 |
| 不锈钢材质 | `Нержавеющая сталь` | 有明确材质资料 |
| 免打孔安装 | `Монтаж без сверления` | 实际安装方式支持 |

遇到“全网第一、百分百有效、永不损坏”等绝对话术，改用有证据的具体结构或参数。不能把防泼溅写成可浸水，把保温结构写成未测试的小时数，或凭食品容器外观添加安全认证。没有依据时删去主张或放待确认备注，不换成另一个无依据卖点。

用户需要核对时，给出“中文意图 / 俄语成稿 / 事实依据”的简短对照。

## 类目关键差异

- **家居日用**：内外尺寸、场景道具是否包含、安装条件、食品接触用途、承重依据。
- **服饰鞋包**：真实颜色、尺码测量口径、成分、模特与平铺差异；不能仅凭通用换算表把尺码标为俄码。
- **3C 数码**：接口、插头、电压、功率、兼容型号、协议与配件；外观相似不能证明兼容。
- **美妆等类目**：净含量、包装版本、用途与使用说明；普通护理描述不扩写成医疗疗效。

## 视觉复核

对照素材检查 SKU 外观、配件数量与真实标识；逐字检查俄语、数字、单位和尺寸线；在原尺寸与缩略图下检查裁切、对比度、错字、缺字、背景融边和文字溢出。箭头不能标到另一条边。场景道具不得误导买家以为包含在套装中。
