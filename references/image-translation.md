# 图片文字翻译与原位替换

用于把已有图片中的源语言文字翻译为俄语，并在原图上替换。源语言可为中文、英文或其他能可靠识别的语言；一张图有多种语言时按区域识别。不要先翻成中文再转俄语造成信息损失。用户指定其他目标语言或只翻译某些区域时，按其要求执行。

## 输入与交付范围

- 先实际查看原图；OCR 或视觉模型用于辅助读取，最终以可见文字核对。纯文本模型不能直接读取像素，需先提供图片理解或 OCR 工具；不能假定技能自带这些能力。
- “图片翻译/原图换俄语文字”默认需要修改后的图片；“提取文字/只翻译文案”只需译文。单张请求处理单张，批量按原始文件逐一对应，不擅自增加图片数量。
- 默认保留原尺寸、宽高比、背景、配色、图序和商品位置，另存新文件。用户要求重新设计或有明确上传规格时才改变画布。
- 读取 [俄语与排版规范](layout-and-copy.md#中文转自然俄语)；准备导出时读取 [导出检查](platform-and-export.md#导出检查)。单纯翻译不需要先取得新商品设计简报，也不以尚未核验平台规则为由停止翻译。

## 识别全部文字区域

按阅读顺序检查大标题、副标题、卖点、尺寸线旁文字、表格单元格、步骤编号、图标说明、角落小字、脚注及多语言重复内容。保持每段文字与对应商品、箭头、图标和行列的关联。

内部建立简短区域清单：区域 ID/位置、源语言、原文、俄语译文、处理方式、待核实项。简单图片可用短表；复杂图或 ERP 调用再使用结构化清单。坐标只有实际定位后才记录，不编造 OCR 置信度、框选位置或图片尺寸。

对模糊字符、遮挡、低清小字、`0/O`、`1/I`、小数点、负号、范围符号等逐项核对。尺寸、容量、功率、型号等关键文字不清楚时请求该区域高清图或原文；无法确认的译文保持为空，不凭商品常识补齐。保留清晰的其他区域成果。

## 区分可翻译内容与保留内容

| 区域 | 默认处理 |
| --- | --- |
| 外加标题、卖点、说明、尺寸标签和表格文案 | 翻译并替换，保留原含义和对应关系 |
| 外加参数数字与单位 | 保留数值及量纲，翻译单位写法；不自动换算尺码或物理单位 |
| 品牌名、Logo、型号、SKU、商标、标准代号 | 保留；通用商品名与品牌名分开处理，不能把品牌当普通词翻译 |
| 商品实物上的印字、包装印字、按钮刻字 | 保留实拍内容；需要理解时在图外对照说明，或按用户要求添加不遮挡实物的俄语注释 |
| URL、条码、二维码 | 保留，不重新生成或修改编码内容；周围的说明文字可以翻译 |
| 已有俄语 | 核对后保留；明显错字可修正并说明，不重复叠加译文 |
| 第三方水印、署名、版权标识 | 保留，不借翻译清字去除 |
| 无法辨认的文字 | 标为待核实，保留该区域；不把占位词印到最终图上 |

用户明确要求把包装或实物印字也改成俄语时，按其指定范围制作本地化设计稿；交付说明这是拟议包装/外观方案，不是已生产的实物照片。品牌、型号与条码的更改不能从“翻译文字”中推定。

## 翻译：忠实含义，适配俄语

- 原文 → 俄语逐区对应，保留否定、适用条件、数量、范围、公差与脚注。例如“仅适用于”“不含电池”“最大”不能为缩短文案而删除。
- 使用自然俄语和一致商品术语；不能为营销效果增加“认证”“食品级”“防水”“医用”“官方推荐”等原文没有的主张。必要缩写不得改变含义。
- 核对数值与对应 SKU。例：`500 ml` → `500 мл`，`1.5 L` → `1,5 л`，`25 × 15 × 8 cm` → `25 × 15 × 8 см`，`2 pcs` → `2 шт.`，`≤ 5 kg` → `≤ 5 кг`。本地化小数符号和单位文字不能改变量值；尺寸顺序、箭头和方向保持对应。
- 保留技术代码、版本和品牌的正式写法，不把型号中的字母改成外观相似的西里尔字母；普通俄语单词也不能混入拉丁近形字母。
- 尺码按原表翻译，原图无俄码时不自行补出俄码换算。币种与价格不按猜测汇率折算。原图已有价格、促销等内容不能因为新图设计习惯就静默删掉。
- 原图只能证明“写了什么”，不能证明性能或认证真实。纯译文可以忠实翻译并在图外备注疑点；要作为可发布商品图使用时，将与资料冲突、无法确认的关键主张标为待核实，不强化、不静默换成另一卖点。用户允许保留原文翻译时可交付草稿，并说明未核实之处。

语言示例仅示范含义，不是任意商品都具备的属性：

| 源文 | 俄语 | 核对重点 |
| --- | --- | --- |
| 不含电池 / Batteries not included | `Батарейки не входят в комплект` | 不漏掉否定和不包含关系；电池类型按资料用词 |
| 仅适用于室内 / For indoor use only | `Только для использования в помещении` | 不省略“仅” |
| 约 500 毫升 / Approx. 500 ml | `Около 500 мл` | 保留近似含义 |
| 最高承重 5 kg / Maximum load 5 kg | `Максимальная нагрузка — 5 кг` | 原文主张待核实时记录，不改成更高承重 |

## 在原图上替换文字

1. 使用原图或无字原始素材，标明替换区域和商品保护区域。仅在文字所在背景做局部清字，不把整张商品重新生成一遍。
2. 文字覆盖商品细节、包装、复杂纹理时，优先使用无字素材或可编辑源文件；没有可靠素材时保留受影响区域，必要时另放俄语注释并明确这是注释版，不能把猜出的细节称为原物还原。
3. 将已核对的俄语放回对应位置。多行、数字、表格和尺寸图优先使用可控排版工具，选覆盖西里尔字母的字体。图片生成/编辑服务可用于局部清字或背景修复，但输出仍需逐字检查。
4. 俄语变长时先合理换行、调整该文字框与邻近留白，再适度调整字号/字距。保持信息层级、读序、箭头关系和边距，不拉伸文字或商品，不把小字缩到无法阅读；保不住原布局时使用最小范围重排并告知。
5. 对照原图检查非文字区域。不能顺便改变商品颜色、材质、接口、配件数量、Logo、背景风格或裁切；用户明确要求的其他编辑除外。

批量图共用术语表、字体和翻译风格，不跨 SKU 复用数值。商品名称、同一卖点在各图保持一致，每个文件单独记录成功、部分完成或待核实；一张图缺素材不阻止其他图完成。

## 逐区验收与交付

- 对照区域清单检查是否漏译、串行串列、误删脚注、残留旧字或重复叠字；保留原文的区域说明理由。“全部替换”不能包含仍待核实的区域。
- 把导出图重新打开，人工视觉核对俄语拼写、词形、否定、数字/单位/型号；有 OCR 时可重新提取作辅助，不能只相信同一模型的完成声明。
- 原尺寸检查清字补丁、边缘、文字溢出、缺字方框和商品是否被误改；约 300 px 宽缩略图检查标题与主体可读性，细节表格仍以原尺寸完整可读为准。
- 交付另存的俄语图片；必要时附简短原文/译文对照及未解决项。没有另存可编辑图层时不声称有可编辑源文件。命名可用原文件名加 `_ru_v1`，不要覆盖原图。
- 存在未处理区域或未核实关键主张时标为草稿/部分完成。无法实际生成图片时交付译文和替换方案，明确尚未回写到图片；缺少工具不会用普通文本模型的回答冒充成图。

## ERP 或程序调用时的结构化交付

仅当调用方需要机器可读结果时使用；普通用户任务直接交付图片。沿用调用方提供的 schema；未提供时可用以下字段，图片路径/URL 仅填写实际保存或上传成功的结果。`bbox` 可省略；提供时为原图像素坐标 `[x, y, width, height]`。

```json
{
  "source_image": "sku123_01.jpg",
  "target_language": "ru",
  "status": "text_only",
  "output_image": null,
  "regions": [
    {
      "id": "r1",
      "location": "右下角说明",
      "source_language": "en",
      "source_text": "Batteries not included",
      "target_text": "Батарейки не входят в комплект",
      "action": "replace",
      "issues": []
    }
  ],
  "issues": ["译文已整理，尚未编辑和导出图片"]
}
```

`action` 使用 `replace`、`preserve`、`annotate` 或 `review`；看不清的 `source_text` / 未确定的 `target_text` 可为 `null`。`status` 使用 `completed`、`partial`、`text_only` 或 `blocked`；`completed` 仅表示所需图片已导出并完成上述检查，不代表 Ozon 审核通过。批量返回每张图的独立记录。
